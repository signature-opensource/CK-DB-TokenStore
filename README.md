# CK-DB-TokenStore

Contains [CK.DB.TokenStore](CK.DB.TokenStore/README.md), which implements the `CK.tTokenStore` table:
a generic store for opaque, expirable and revocable tokens, keyed by a unique (Scope, Key) couple.

Built on [CK.DB.Actor](https://github.com/signature-opensource/CK-DB/tree/develop/CK.DB.Actor#readme).
